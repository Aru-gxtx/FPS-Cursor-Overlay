Previously named "FPS Cursor Overlay", was changed because the URL for this was too long and difficult to type. cursorrg is a tool that allows you to overlay an image onto the screen, displaying it as a crosshair.

## Installation Instructions

1. Download the latest `.zip` file in the [release](https://github.com/Aru-gxtx/cursorrg/releases) section.
2. Unzip and run `run.exe`.
3. Select an existing cursor or add a new one.
4. Start the cursor with "Run cursor" and close it with "Close cursor".

> [!NOTE]
> * "Close cursor" only closes the cursor overlay, not the cursor gallery UI *(I could just rename it to "Close overlay," but since it's already been released, I'll fix it in the next release (if the confusion persists)).*
> * Alternatively, you can close the cursor gallery UI with the window application's default close button.
